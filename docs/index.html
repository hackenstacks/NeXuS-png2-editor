What it does

Everything your character cards need

A single Python file. No database, no config required. Just point it at your cards directory.

🖼️
Visual Card Browser
Grid view of all your PNG character cards with portraits, names, descriptions and tags. Live search to filter instantly.
✏️
Full Field Editor
Edit every field in the chara_card_v2 spec — name, description, personality, scenario, system prompt, first message, post-history instructions, tags, creator notes.
💾
Save Back to PNG
Writes your edits into the PNG tEXt chunk. The image pixel data is never touched — only the embedded character metadata changes.
⬡
aichat Role Export
One click exports any card as a role file to ~/.config/aichat/roles/ — instantly available in the aichat playground Role dropdown.
{}
JSON Export
Download the full chara_card_v2 data as a .json file. Compatible with SillyTavern, TavernAI, and any tool that reads the spec.
🏴
100% Local & Private
No cloud, no telemetry, no API keys. Runs on localhost:7420. Your character cards never leave your machine.
Export Options

Three ways to export

Every card can be saved, exported as a role, or downloaded as JSON — from the same editor view.

💾
Save PNG
Writes edits back into the source PNG file. Non-destructive — image data unchanged, only the embedded chara metadata is updated.
⬡
Export .md → aichat
Merges description, personality, scenario, system_prompt and post_history_instructions into a single aichat role file. Appears in the playground immediately.
{}
Export JSON
Downloads the full chara_card_v2 JSON to your machine. Compatible with SillyTavern, TavernAI, and any tool that reads the standard spec.
Getting Started

Up in 60 seconds

Two dependencies. One command to run. No database, no config file.

1

Clone the repo

git clone https://github.com/hackenstacks/NeXuS-png2-editor
cd NeXuS-png2-editor
2

Install dependencies

pip install flask pillow
3

Run the editor

python3 nexus_png2_editor.py

Point at a custom cards directory: CARDS_DIR=~/my-cards python3 nexus_png2_editor.py

4

Open in browser

http://localhost:7420
★

Optional: Install aichat for role export

# Download pre-built binary (Linux x86_64)
wget https://github.com/sigoden/aichat/releases/latest/download/aichat-x86_64-unknown-linux-musl.tar.gz
tar xzf aichat-*.tar.gz && mv aichat ~/.local/bin/

# Or install via Cargo
cargo install aichat

# Start the playground
aichat --serve
# → http://localhost:8000/playground
